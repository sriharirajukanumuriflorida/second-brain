# Inbox Processing Checklist

For each item in 00 Inbox:

1. Is this a reference or highlight?
   → Convert to Literature Note (Cmd + Shift + L)

2. Is this an idea or insight?
   → Convert to Permanent Note (Cmd + P)

3. Is this code?
   → Convert to Code Snippet (Cmd + Shift + C)

4. Is this a task?
   → Move to Daily Note or Project

5. Is this trash?
   → Delete

Goal: Inbox empty every day.
