## Summary
- Introduces supervised learning and focuses on regression for predicting continuous values.

## Key Ideas
- Supervised learning uses labeled data to learn input-to-output mappings.
- Regression predicts continuous targets (e.g., linear regression and variants).
- Evaluation with error metrics such as MSE, RMSE, and R-squared.

## Important Details
- Regression is the entry point into predictive modeling before classification.
- Notebooks demonstrate supervised learning and regression applications.
