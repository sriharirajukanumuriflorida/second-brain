# Convolutional Neural Networks Learn Spatial Features

## Core Idea
- Convolutional neural networks learn patterns in image data by extracting local spatial features across multiple layers.

## Why It Matters
- They are one of the most important model families for computer vision.
- They make image classification, detection, and feature extraction practical at scale.

## Explanation
- CNNs use convolution filters to detect patterns such as edges, textures, and shapes.
- Pooling and deeper layers help compress and refine those patterns into higher-level representations.
- This layered spatial learning makes CNNs especially effective for images compared with fully connected networks alone.

## Examples
- Image classification with a CNN on labeled image datasets.
- Using CNN backbones inside transfer learning and object detection pipelines.
