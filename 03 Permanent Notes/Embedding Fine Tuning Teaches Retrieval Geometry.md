# Embedding Fine Tuning Teaches Retrieval Geometry

Embedding-model fine-tuning changes the vector space so relevant query-document pairs are close and irrelevant pairs are far. It is a ranking problem optimized with contrastive evidence, not a generation problem.

> One-liner: **tune the geometry, then measure the ranking.**
