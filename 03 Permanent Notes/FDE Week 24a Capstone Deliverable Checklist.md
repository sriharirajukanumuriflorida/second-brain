# FDE Week 24a Capstone Deliverable Checklist

Copy this checklist into every FDE portfolio capstone review.

| Deliverable | Quality signals |
|---|---|
| GitHub repo | `src/`, `tests/`, `prompts/`, `evals/`, `infra/`, `docs/`, ADRs, CI passing, LICENSE, CODEOWNERS |
| README | BLUF business claim, 5-minute run, architecture diagram, eval table, screenshots/GIF, video link, cost/query, security summary |
| Architecture diagram | C4 Container-level diagram generated from Mermaid or PlantUML source |
| API documentation | FastAPI-generated OpenAPI, Swagger UI, examples, versioned endpoints |
| Prompt contract | id, purpose, version, expected schema, safety rules, owner, changelog |
| Evaluation report | 100-500 golden examples, harness, score by category, regression table, chart, sampled failures |
| Demo video | 3-5 minute three-act arc: problem, capability, measurable outcome |
| Deployment guide | local docker compose and cloud deploy with Terraform or Bicep plus exact CI/manual commands |
| Risk checklist | threat model, PII/DLP notes, go-live checklist, compliance posture, mitigations and owners |
| Roadmap | not built, next steps, business rationale, revisit triggers |

Readiness rule: if a reviewer cannot clone, test, eval, run, and understand the risk posture without you, the capstone is not handoff-ready.

> One-liner: **portfolio-ready means reproducible value plus inspectable evidence.**
