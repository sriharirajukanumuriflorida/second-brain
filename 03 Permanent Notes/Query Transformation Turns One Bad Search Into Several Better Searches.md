# Query Transformation Turns One Bad Search Into Several Better Searches

Users ask conversational questions, but retrievers need search probes. Query transformation rewrites the raw question into forms that match the corpus: HyDE hypothetical passages, paraphrase sets, decomposed subquestions, step-back abstractions, or routes to specialized sources.

The transformed text is a retrieval aid, not evidence. Final answers must cite real retrieved documents.

> One-liner: **transform for recall, ground on real evidence.**
