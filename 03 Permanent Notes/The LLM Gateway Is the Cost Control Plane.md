# The LLM Gateway Is the Cost Control Plane

An LLM gateway centralizes the policies that otherwise sprawl across applications: provider keys, model aliases, budgets, retries, fallbacks, caching, routing, logging, and per-tenant limits. This turns cost management from a monthly invoice surprise into an enforceable runtime control.

Gateways also make experimentation safer: teams can switch model aliases, tune routes, enforce budget ceilings, and compare providers without rewriting every application path.

> One-liner: **put spend policy in the request path** — not in a spreadsheet after the fact.
