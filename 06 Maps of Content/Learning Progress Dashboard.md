# Learning Progress Dashboard

> One checklist for the full FDE/AI-ML curriculum, in actual prerequisite order, 9 phases — Software Engineering → Applied Data Science → Classical ML → Deep Learning → Generative AI → LLM Engineering → AI Architecture → FDE Delivery. No timeline attached — work it at whatever pace your schedule allows; progress is measured in topics done, not weeks elapsed.
> This file is the **tracker** (check boxes as you complete topics). For the **explained reading path** with full prose per topic, use [[06 Maps of Content/AI-ML Topics Covered — Chronological]]. For deep per-domain status (✅/🟡/⬜ + snippets + permanent notes), use each domain's own MOC linked below.
>
> Check a box when you've read the Literature Note, worked its notebook/snippet if one exists, and could pass its Self-Check. Progress % is manual — recount after a study session, no need to keep it exact in real time.

## How to use this
1. Work top to bottom — each phase assumes the ones above it are done.
2. Within a phase, the numbered order is the suggested read order (matches each domain's own MOC).
3. Tick the box in this file when done. The link still points to the real note for depth/snippets/Q&A.
4. If a phase's own MOC marks a topic 🟡 (partial) rather than ✅ (built), treat it as present but shallower — tick it once you've personally closed that gap, not just because the vault marks it built.
